# Methodology

One short note per stage of the project: what was done, why, and the key
numbers. Figures are generated by `scripts/make_figures.py` into
`outputs/figures/`. Dated details and earlier results are in
[`../03_decisions_log.md`](../03_decisions_log.md).

|---|---|---|
| 1 | [The corpus](01_corpus.md) | 87 articles from the official text; 47 have no citation link to any other |
| 2 | [Atoms](02_atoms.md) | 30 articles split into 80 labelled atoms; leave-one-out MRR 0.61 |
| 3 | [Test set from court judgments](03_case_law_test_set.md) | 707 judgments citing the WGBO → 395 questions, 126 dev / 269 test |

| 5 | [Score spreading](05_score_spreading.md) | Passing scores along citation and section links: nDCG@10 0.32 → 0.35 |
